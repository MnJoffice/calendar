# 제주 2026 캘린더

제주의 계절 정보와 2026년 일정을 한눈에 확인하고, 날짜별 할 일을 기록할 수 있는 반응형 웹 캘린더입니다.

서비스 바로가기: [제주 2026 캘린더](https://jeju-calendar-2026.meishan-sung.chatgpt.site)

## 주요 기능

- **2026년 월간 달력**: 1월부터 12월까지 월 단위로 이동하며 날짜를 확인할 수 있습니다.
- **날짜별 할 일 관리**: 원하는 날짜를 선택해 할 일을 추가하고, 완료 처리하거나 삭제할 수 있습니다.
- **자동 저장**: 할 일은 브라우저의 `localStorage`에 저장되어 같은 기기와 브라우저에서 다시 방문해도 유지됩니다.
- **제주 행사 안내**: 성산일출축제, 탐라문화제, 제주올레걷기축제 등 2026년 제주 주요 일정을 달력에서 확인할 수 있습니다.
- **개화 시기 안내**: 유채꽃, 왕벚꽃, 수국, 억새, 동백 등 월별 제주 식생과 추천 장소를 제공합니다.
- **반응형 화면**: 데스크톱, 태블릿, 모바일 환경에 맞춰 화면 구성이 조정됩니다.
- **계절 표현**: 봄, 여름, 가을, 겨울에 맞는 계절 문구와 움직이는 계절 이모지가 표시됩니다.

## 이용 방법

1. 왼쪽 월 메뉴 또는 달력 상단의 이전·다음 버튼으로 원하는 달을 선택합니다.
2. 달력에서 날짜를 선택합니다.
3. 오른쪽 패널에서 해당 날짜의 제주 행사 정보를 확인합니다.
4. `할 일을 입력하세요` 칸에 내용을 작성하고 **추가** 버튼을 누릅니다.
5. 체크박스로 완료 상태를 변경하거나 `×` 버튼으로 할 일을 삭제합니다.

모바일에서는 월 메뉴가 화면 상단에 가로로 표시되며, 날짜를 선택한 뒤 화면 아래에서 일정과 할 일을 확인할 수 있습니다.

## 디자인

- 메인 컬러: 레드·딥 크림슨
- 글꼴: Pretendard
- 그라디언트와 점 형태의 인디케이터를 사용하지 않은 플랫 디자인
- 계절 이모지를 제외한 장식용 이모지 미사용

## 기술 구성

별도의 프레임워크나 빌드 과정 없이 HTML, CSS, JavaScript로 제작한 정적 웹 앱입니다.

```text
dist/
├── index.html   # 페이지 구조와 기본 메타데이터
├── styles.css   # 레이아웃, 레드 테마, 반응형 스타일
└── app.js       # 달력 생성, 제주 정보, 할 일 저장 및 상호작용
```

## 로컬 실행

정적 파일 서버의 루트를 `dist` 폴더로 지정해 실행합니다. 예를 들어 Node.js 환경에서는 다음과 같이 간단한 정적 서버를 사용할 수 있습니다.

```bash
npx serve dist
```

명령 실행 후 터미널에 표시된 로컬 주소를 브라우저에서 열면 됩니다.

## 데이터와 저장 범위

- 제주 행사와 개화 정보는 [비짓제주 공식 관광정보](https://www.visitjeju.net/kr/festival/list)를 참고해 구성했습니다.
- 행사 일정은 주최 측 사정에 따라 변경될 수 있으므로 방문 전에 공식 일정을 다시 확인하는 것을 권장합니다.
- 개화 시기는 날씨와 지역에 따라 달라질 수 있으며, 앱에 표시된 기간은 여행 계획을 위한 예상 정보입니다.
- 할 일 데이터는 서버나 계정에 동기화되지 않고 현재 브라우저에만 저장됩니다. 브라우저 데이터를 삭제하거나 다른 기기에서 접속하면 기존 할 일을 불러올 수 없습니다.

## 브라우저 지원

최신 버전의 Chrome, Edge, Safari, Firefox에서 사용할 수 있습니다. `localStorage`가 차단된 환경에서는 할 일 저장 기능이 제한될 수 있습니다.
